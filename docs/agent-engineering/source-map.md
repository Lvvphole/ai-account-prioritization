# Agent Engineering Standard — Source Map

This file records the authorities used to synthesize the admitted rules. It is not runtime context.

- `STE100` — ASD-STE100 Simplified Technical English, Issue 9 (2025): General Introduction; Parts 1 §§5–6.
- `REQ3` — Karl Wiegers and Joy Beatty, *Software Requirements*, 3rd ed.: Chapters 1, 11, 17.
- `CleanCode` — Robert C. Martin et al., *Clean Code*: Chapters 1–4, 7, 9–10, 12, 17.
- `Ousterhout` — John Ousterhout, *A Philosophy of Software Design*: Chapters 2–5, 8–10, 13–18, 20.
- `CodeComplete` — Steve McConnell, *Code Complete*, 2nd ed.: construction, routines, software quality, refactoring.
- `Fowler` — Martin Fowler et al., *Refactoring: Improving the Design of Existing Code*: Chapters 1–4.
- `AgileRequirements` — Dean Leffingwell, *Agile Software Requirements*: acceptance testing and precise specification.
- `HardParts` — Neal Ford et al., *Software Architecture: The Hard Parts*: ADRs, trade-off analysis, coupling, modularity, contracts, data ownership, fitness functions.
- `EffectivePython` — Brett Slatkin, *Effective Python*, 2nd ed.: Items 20, 84, 90.
- `EffectiveTS` — Dan Vanderkam, *Effective TypeScript*, 2nd ed.: Items 5, 9, 29, 31, 40, 45, 46.
- `AgentBench` — *Evaluating AGENTS.md: Are Repository-Level Context Files Helpful for Coding Agents?* (2026): task specification and regression-test methodology.
- `ContextEngineeringLock` — Project decision: store broadly, load narrowly, enforce deterministically; author rules before engineering more machinery.
